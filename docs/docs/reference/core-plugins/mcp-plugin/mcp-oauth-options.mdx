### tokenSecret

<MemberInfo kind="property" type={`string`}   />

Server secret used to HMAC-hash OAuth tokens at rest. Generate once via
`openssl rand -base64 32`. Required to enable OAuth. Supply via an
environment variable. Rotating the secret invalidates all stored MCP OAuth
tokens.
### issuer

<MemberInfo kind="property" type={`string`} default={`'http://localhost:3500'`}   />

Public base URL of the Vendure server, used as the OAuth issuer and to build
authorization-server / protected-resource metadata URLs.
### accessTokenTtlSeconds

<MemberInfo kind="property" type={`number`} default={`900`}   />

Lifetime of an issued access token, in seconds.
### refreshTokenTtlSeconds

<MemberInfo kind="property" type={`number`} default={`2592000`}   />

Lifetime of an issued refresh token, in seconds.
### authorizationCodeTtlSeconds

<MemberInfo kind="property" type={`number`} default={`60`}   />

Lifetime of an authorization code before it must be exchanged, in seconds.
### authorizationRequestTtlSeconds

<MemberInfo kind="property" type={`number`} default={`600`}   />

Lifetime of a pending authorization request (consent window), in seconds.
### adminConsentPath

<MemberInfo kind="property" type={`string`} default={`'/dashboard/mcp/authorize'`}   />

Path (relative to `issuer`) of the admin consent page that approves
admin-scoped authorization requests.
### storefrontConsentUrl

<MemberInfo kind="property" type={`string`} default={`'http://localhost:3000/mcp/authorize'`}   />

Absolute URL of the storefront consent page that approves customer-scoped
authorization requests.
### grantRetentionDays

<MemberInfo kind="property" type={`number`} default={`30 (days)`}   />

How long to keep a grant after it dies, by expiry or revocation, before the row itself is
deleted. The grant is the only OAuth record with anything to audit, so it outlives the
authorization it recorded.

Each tool-call log references the grant it was made under, and that link is nulled when the
grant is deleted. Set this at or above `McpLoggingOptions.ttlDays` if every retained
log should still be able to resolve its grant.
### retentionSchedule

<MemberInfo kind="property" type={`McpRetentionSchedule`} default={`cron => cron.everyDayAt(3, 30)`}   />

Schedule for the cleanup job that prunes OAuth records which can no longer be used: the
Vendure session minted for each expired grant, expired or spent authorization requests and
codes, and grants dead for longer than `grantRetentionDays`.
